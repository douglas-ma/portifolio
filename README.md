# Portfólio de Douglas Araújo

Site estático de uma página, com as seções Projetos, Sobre Mim, Habilidades, Experiências e Contatos.

## Prévia local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP local:

```powershell
python -m http.server 8765
```

## Atualizar a versão publicada

Edite `index.html`, `styles.css` ou `script.js` e copie os arquivos para `dist/` antes de publicar. A hospedagem usa `dist/` conforme `.openai/hosting.json`.

O conteúdo biográfico foi baseado em `Curriculo_Douglas.pdf`, fornecido pelo titular. O PDF não é distribuído com este repositório.
